# Changelog

Notable changes to Legacy Plugin, loosely following [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-10-15

First release. Legacy Plugin brings other mods' `Dunia.dll` tweaks to the running game as settings,
so no patched `Dunia.dll` is needed. It is an FCSE plugin and needs FCSE 1.4.0 or later.

### Added
- **Seventeen tweaks other mods make by patching `Dunia.dll`**, each a row in the Mod
  Configuration menu that leaves the game as it shipped until switched on: briefings that keep
  control, keeping your weapon on a buddy rescue, no forced buddy rescues, no reputation drop, no
  diamond message, no blinking pickups, no save icons on the map, limited saving, the brown filter,
  no hit indicator, the HUD's fade-out time, skipping tutorial pop-ups, aim and sprint toggles,
  sprint turn, no rim lighting and no sprint and aim blur. From Scubrah's Patch, Realism Plus and
  FC2JackalFix.
