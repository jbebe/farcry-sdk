# Scubrah's Patch 3.7

A gameplay and bugfix overhaul by scubrah, the second of the two base-patch lineages most later
mods build on (see the [mods survey](../../docs/docs/modding/mods-survey.md)). It folds in scubrah's
earlier standalone mods - Fix Bouncing NPCs, Functional Outposts, Skip Intro - and fixes credited to
FoxAhead, Boggalog, Lasercar, miru, Parallellines and Dzert14.

The mod requires a new game: much of it is new mission layers and scripts that a save made without
them does not have.

## How it ships

| In the archive | What it is |
|---|---|
| `Far Cry 2/Data_Win32/patch.dat`, `patch.fat` | A full replacement patch archive: 211 files and 10,548 fragments differ from the base game; everything else is the base game repacked. |
| `Far Cry 2/bin/Dunia.dll` | The Steam 1.03 `Dunia.dll` (`fc2_103_uplay`) with 19 code patches and two edited strings. On a GOG install it replaces GOG's own build. |
| `Far Cry 2/bin/farcry2.exe` | The retail launcher with the large-address-aware flag set. Its code is the same as Steam's. |
| `Far Cry 2/ScubrahsPatch.lua` | The player's settings: outpost, patrol and armory respawn delays, map marker, fast travel cost, malaria, colour grading, darker nights. |
| `Far Cry 2/Far Cry 2 FOV Changer.vbs` | A script that rewrites the FOV in the installed `patch.dat` in place. |

Much of the mod's logic is new Domino scripts, generated by scubrah's own tool and stored nameless
(`_hash/*.lua`). Each opens with the feature it belongs to, e.g. `-- Generated for "Functional
Outposts" v1.0`.

## Bundles

- `features` - the nine headline features
- `gameplay`, `balancing`, `visuals`, `fixes` - the four sections of the list
- `randomized-patrols` and `improved-graphics` - headline features made of several components

## Published feature list

### Features

- Randomized Patrols: Custom dynamic patrol system which randomizes enemy vehicles, occupants and their factions
- Functional Outposts: After clearing an outpost, the enemies within it will not respawn until 45 minutes (real time) has passed
- Skippable Intro: Allows you to skip the long intro sequence and start the game at the hotel in town
- Concurrent Missions: Allows you to complete all mission types simultaneously
- Faction Conflicts: Encounter random enemy firefights between the APR & UFLL
- Skippable Dialog: Allows you to skip scripted NPC animations & dialog by interacting with them
- Improved Graphics: Disables brown filter, increases draw distance, improves clouds and lighting, increases shadow resolution & range and more
- DX10 Compatibility: Play with the DX10 API for higher framerates
- User Configurable: Tweak various mod features to your liking within the external configuration file
