RaZoR's samples of running Lua in an editor map, through archetypes that carry a `CDominoComponent`.
They come with the editor mod this one is built on and need its `dlc2` library loaded
([`editor-razor-library`](editor-razor-library.md)). Two more scripts in the same style are loaded by
nothing ([`noise-scripts-unreferenced`](noise-scripts-unreferenced.md)).
