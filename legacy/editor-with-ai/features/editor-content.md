The editor mod this one is built on, credited to Janne252 in the editor title, with custom objects
named for RaZoR. Its palette, inventory and template-world files carry the header comment of the
tool they were saved with, "Far Cry 2 - Multi... Editor v1.3.2.2". Most RaZoR objects come from the
`dlc2` library ([`editor-razor-library`](editor-razor-library.md)), which this archive does not
register.
