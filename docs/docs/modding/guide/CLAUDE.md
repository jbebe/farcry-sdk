# Almost Complete Guide - static content

This folder is Boggalog's "An Almost Complete Guide to Far Cry 2 Modding", converted from the
author's Google Docs export into one page per top-level section of the original. It is someone
else's writing, reproduced as-is - not documentation this repo maintains.

- Never rephrase, restyle, reorder, merge, split, summarize or "correct" these pages, including
  during a docs-wide rewrite or consistency pass.
- Never add notes, callouts, provenance tags or cross-links inside the guide's text. Where the guide
  is wrong or outdated, say so on a page outside this folder and link in, the way
  `docs/docs/modding/gotchas.md` does.
- The only acceptable edit is repairing a conversion defect - broken markdown, a link or anchor that
  fails `npm run build` - without changing the wording.

The repo-authored parts are the opening callout and the table of contents in `index.md`, and
`_category_.json`. This file is kept off the site by `docs.exclude` in `docs/docusaurus.config.js`.
